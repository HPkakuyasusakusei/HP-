制作側の連想

「悠遊」から、けん玉を思い浮かべました。

屋号の「遊」の字から、制作側は「あそび」を連想し、さらにけん玉を思い浮かべました。けん玉には大皿・中皿・小皿・けん先・とめという受け皿や部位があります。このサイトは、その名前を5つのページの目印に借りています(上のレールの赤い玉が、いま開いているページです)。これは制作側の連想で、お店の理念・由来とは無関係です。お店がけん玉と関係しているという意味でもありません。

五つの受け皿

ページの名前は、けん玉の部位から。

  1. 中皿店のこと確認できていることと、制作側の想像を分けて並べました。
  2. 小皿メニューメニューと価格は準備中です。
  3. けん先口コミ制作側が創作した「イメージ例」です。
  4. とめアクセス住所と地図、電話番号をまとめています。
