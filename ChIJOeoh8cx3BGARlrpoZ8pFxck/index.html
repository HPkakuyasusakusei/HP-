制作側の連想

綴りを、歩いてみる

SORRIVO を左から順に、S → O → R → R → I → V → O と歩く経路として見てみます。文字の種類は S・O・R・I・V の5つで、それぞれを「部屋」とします。S は入口で、通るのは一度きり。R は二つ続くので、同じ部屋で足踏みします。最後の O は二度目の訪問で、O → R → I → V → O と、ひとまわりして輪が閉じます。

この見方は制作側の連想で、お店の理念・由来とは無関係です。屋号の意味や読み方は分かっていません。

  1. S入口
  2. O最初の部屋
  3. R足踏み(RR)
  4. I部屋
  5. VO へ戻る

このサイトの5ページは、この部屋の順に並べました。ホームが S、店のこと・メニュー・口コミ・アクセスがそれぞれ O・R・I・V です。V のあとは、はじめの O(店のこと)に戻ります。

もうひとつの綴り

CAFFETTERIA にも輪がある

CAFFETTERIA を同じように歩くと、C → A → F → F → E → T → T → E → R → I → A。A から出て F・E・R・I をまわり、A に戻る輪ができます。途中、E から T へ寄り道して(T は足踏み)E に戻ります。F も足踏みです。

CAFFETTERIAC → A → F↻ → E → T↻ → E → R → I → A(輪が閉じる)

SORRIVOS → O → R↻ → I → V → O(輪が閉じる)
