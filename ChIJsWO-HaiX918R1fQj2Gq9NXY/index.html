ジャーニーブレッド

富山県中新川郡上市町にあるパン屋「ジャーニーブレッド」のご案内ページです。営業時間やメニューなど、詳しいことは準備中。電話とInstagramからご連絡ください。

NOTE

「ジャーニー」から連想した、荷造りの順

屋号の由来は分かりません。制作側は「ジャーニー(旅)」という言葉から、リュックに荷物を詰める手順を連想しました。底に最初のもの、口に最後のもの。このサイトの5ページを、リュックの5つの層に見立てています。お店の理念や由来とは無関係の、制作側の連想です。

PACK ORDER

リュックの底から口まで、五つの層

写真は上市町やお店のものではありません。国外・撮影地不明のフリー素材を、層のイメージで並べたものです。

  1. 蓋01

    いちばん上、すぐ手が届く場所。

  2. 上02

    出し入れの多いものを入れる段。

  3. 中03

    背中に近い、重心のあたり。

  4. 下04

    軽くてかさばるものを入れる段。

  5. 底05

    いちばん下、最初に入れるもの。
