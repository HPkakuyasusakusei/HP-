cafe X

長崎県長崎市のカフェ「cafe X」のご案内ページです。営業時間やメニューなど、詳しいことは準備中。まずはInstagramをのぞいてみてください。

C は、重心の点が字のうしろの空っぽの場所に落ちます。指を当てたい点に、墨が無い字です。

金色の丸が、この図の字の重心の点です。下の小さな字を押すとそのページへ移動します。

制作側の連想

字を厚紙で切り抜いて、指で支えるなら

これは制作側の連想で、お店の理念・由来とは無関係です。「C・A・F・E・X」の5つの字を、それぞれ一筆書きの線で描いた厚紙の切り抜きだと考えます。指1本で水平に支えられる点、つまり重心はどこにあるでしょう。

答えは字によって違います。C・A・F の点は、字のなかの空っぽの場所に落ち、墨の上には乗りません。E と X の点は、ちゃんと棒の上に乗ります。5ページはそれぞれ、1字ぶんの点の場所を見ていきます(図は制作側が描いた字形での話です)。
