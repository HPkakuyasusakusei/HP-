制作側の連想

店名「パンの香り」から、香水の「ノート」を思った

店名はフランス語で「パンの香り」という意味だと思われます(由来は分かりません)。制作側はここから、香水が「トップ・ハート・ベース」の順に香りを重ねて語られることを連想し、このページを3つの香りの層に見立てて並べました。パンの香りを、立ちのぼる香り、中心の香り、あとに残る香りに分けて眺める、という遊びです。お店の理念や由来とは無関係の、制作側の連想です。

3つの香りの層(イメージ)

写真は大野市やお店のものではありません。国外・撮影地不明のフリー素材を、香りのイメージで並べています。お店で扱う商品を示すものでもありません。

Top note

立ちのぼる香り

扉を開けて最初に感じる、香ばしい焼き色のイメージ。

Heart note

中心の香り

小麦と粉、生地。パンの芯にあたるイメージ。

Base note

あとに残る香り

窯の火、夕焼けの麦畑。余韻のイメージ。
