採点のしかた

文字を一つずつ、三色で。

※ このテーマは制作側の連想で、お店の理念・由来とは無関係です。屋号を英単語ごとに分け、綴りだけを見て採点する遊びで、単語の意味は扱いません。

三つの色

  • Aぴたり: 答えに同じ文字があり、左から数えた位置も同じ
  • Aずれ: 答えに同じ文字はあるが、位置がちがう
  • Aなし: 答えにその文字がない(残りの数も含む)

同じ文字が二つあるときは、先にぴたりを決め、残った分だけをずれにします。左から数えて位置を比べます。

  1. Wずれ
  2. Eなし
  3. Sなし
  4. Tずれ

01 WEST と TOWN

WとTはTOWNにもあるけれど、位置はちがいます。EとSはTOWNにありません。

  1. Tずれ
  2. Oなし
  3. Wずれ
  4. Nなし

02 TOWN と WEST

TとWはWESTにもありますが、位置はちがいます。OとNはWESTにありません。

  1. Cなし
  2. Oぴたり
  3. Fなし
  4. Fなし
  5. Eなし
  6. Eなし

03 COFFEE と TOWN

2文字目のOだけが、TOWNの2文字目と同じ位置で重なります。

  1. Cなし
  2. Oなし
  3. Fなし
  4. Fなし
  5. Eずれ
  6. Eなし

04 COFFEE と WEST

COFFEEのEは二つありますが、WESTのEは一つだけ。そのため、ずれになるのは一つ目のEだけです。

三語の輪

WESTW・TTOWNOCOFFEEEWEST

WESTとTOWNはW・T、TOWNとCOFFEEはO、COFFEEとWESTはE。どの二語を選んでも、重なる文字が少なくとも一つあります。三つの語は、重なりでぐるりとつながった形です。
